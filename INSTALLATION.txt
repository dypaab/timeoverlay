TIMEOVERLAY - INSTALLATION
Version 2.3.0

Chronometrage de culte pour OBS : affiche l'heure, un compte a rebours et le
temps de depassement dans des fichiers texte que les sources Texte d'OBS
lisent et affichent.


===============================================================================
1. OU TELECHARGER
===============================================================================

Toutes les versions sont sur la page des publications :

    https://github.com/dypaab/timeoverlay/releases

Prenez la version la plus recente, en haut de la page. Les fichiers sont sous
le titre "Assets". Il y en a trois : choisissez UN SEUL, selon votre systeme.


   VOTRE SYSTEME                        LE FICHIER A PRENDRE
   ---------------------------------    ---------------------------------
   Windows 10 ou 11                     TimeOverlay-Windows-x64.zip
   Ubuntu 22.04 ou plus recent          timeoverlay_2.3.0_amd64.deb
   Debian 12 ou plus recent             timeoverlay_2.3.0_amd64.deb
   Une autre distribution Linux         TimeOverlay-x86_64.AppImage
   (Fedora, Arch, Mint, openSUSE...)


Lien direct vers la derniere version, si vous preferez :

    https://github.com/dypaab/timeoverlay/releases/latest


===============================================================================
2. INSTALLATION SOUS WINDOWS
===============================================================================

Il n'y a pas d'installateur, et c'est voulu : rien n'est ecrit dans le
systeme, aucun droit administrateur n'est demande.

  1. Telechargez TimeOverlay-Windows-x64.zip

  2. Faites un clic droit sur le fichier > Extraire tout...

     ATTENTION : extrayez vraiment l'archive. Si vous double-cliquez sur le
     ZIP et lancez TimeOverlay.exe depuis l'apercu de Windows, l'application
     ne trouvera pas ses bibliotheques et ne demarrera pas.

     Mettez le dossier obtenu quelque part de stable : Documents, ou la racine
     du disque. Pas dans le dossier Telechargements, qu'on vide un jour sans y
     penser.

  3. Ouvrez le dossier et double-cliquez sur TimeOverlay.exe

  4. Windows affiche peut-etre un ecran bleu "Windows a protege votre
     ordinateur". C'est normal : le programme n'est pas signe par un
     certificat payant. Cliquez sur "Informations complementaires", puis sur
     "Executer quand meme".

  5. Pour le lancer plus facilement ensuite : clic droit sur TimeOverlay.exe >
     Envoyer vers > Bureau (creer un raccourci).

Pour desinstaller : supprimez le dossier. C'est tout.


===============================================================================
3. INSTALLATION SOUS UBUNTU OU DEBIAN (le paquet .deb)
===============================================================================

  1. Telechargez timeoverlay_2.3.0_amd64.deb

  2. Ouvrez un terminal dans le dossier de telechargement et tapez :

         sudo apt install ./timeoverlay_2.3.0_amd64.deb

     Le "./" au debut est indispensable : sans lui, apt cherche un paquet de
     ce nom sur internet au lieu de votre fichier.

     N'utilisez PAS "sudo dpkg -i". dpkg n'installe pas les dependances, et
     l'application ne demarrerait pas.

  3. TimeOverlay apparait dans votre menu d'applications.
     Vous pouvez aussi le lancer depuis un terminal avec :  TimeOverlay

Pour desinstaller :

         sudo apt remove timeoverlay

Pour installer une version plus recente, reprenez simplement la commande
d'installation avec le nouveau fichier : elle remplace l'ancienne.


===============================================================================
4. INSTALLATION SUR UNE AUTRE DISTRIBUTION LINUX (l'AppImage)
===============================================================================

Une AppImage est un fichier unique qui contient tout. Rien ne s'installe.

  1. Telechargez TimeOverlay-x86_64.AppImage

  2. Rendez le fichier executable. En ligne de commande :

         chmod +x TimeOverlay-x86_64.AppImage

     Ou avec la souris : clic droit > Proprietes > Permissions > cochez
     "Autoriser l'execution du fichier comme un programme".

  3. Double-cliquez dessus, ou lancez :

         ./TimeOverlay-x86_64.AppImage

  4. Rangez le fichier a un endroit stable AVANT de l'utiliser vraiment. Si
     vous le deplacez plus tard, le lancement automatique au demarrage
     cherchera l'ancien emplacement et ne trouvera plus rien.

Il faut glibc 2.35 ou plus recent (Ubuntu 22.04 et equivalents).
Si l'AppImage refuse de demarrer, installez FUSE :

         sudo apt install libfuse2

Pour desinstaller : supprimez le fichier.


===============================================================================
5. AU PREMIER LANCEMENT
===============================================================================

Deux choses se passent toutes seules.

  - L'application s'inscrit au demarrage de votre session. Elle affiche
    l'heure et le decompte avant le culte : elle ne sert a rien si personne ne
    pense a l'ouvrir. Pour desactiver : menu Outils > Parametres, decochez
    "Lancer TimeOverlay au demarrage de l'ordinateur". Une fois decochee, la
    case n'est jamais recochee toute seule.

  - Un dossier de sortie est cree. C'est la que sont ecrits les fichiers que
    vous allez pointer depuis OBS :

        Linux    ~/.local/share/TimeOverlay/obs/
        Windows  %APPDATA%\TimeOverlay\obs\

Une seule copie de l'application peut tourner a la fois. Deux copies
ecriraient dans les memes fichiers et OBS afficherait des valeurs
incoherentes. Si un message vous dit que TimeOverlay est deja ouvert,
cherchez-le dans la barre des taches.

6. BRANCHER OBS
===============================================================================

Le plus simple : dans TimeOverlay, cliquez sur le bouton "Chemins OBS". La
fenetre reste ouverte pendant que vous configurez OBS, vous copiez les chemins
un par un.

Puis, dans OBS, pour chaque valeur a afficher :

  1. Sources > + > Texte (GDI+) sous Windows, Texte (FreeType 2) sous Linux
  2. Cochez "Lire depuis un fichier"
  3. Collez le chemin du fichier voulu

Les fichiers disponibles :

    heure.txt            l'heure courante
    date.txt             la date
    countdown.txt        le temps restant sur la phase en cours
    countup.txt          le temps ecoule
    depassement.txt      le temps en trop, une fois zero atteint
    avant_debut.txt      le decompte avant le debut du culte
    phase.txt            le nom de la phase en cours
    phase_suivante.txt   le nom de la phase d'apres
    statut.txt           EN_COURS, PAUSE, DEPASSEMENT...
    message.txt          un mot ponctuel a l'intervenant
    annonce.txt          les annonces qui defilent

LE TRUC A CONNAITRE : depassement.txt reste VIDE tant que la phase ne deborde
pas, et une source Texte vide n'affiche rien dans OBS. Creez donc une source
en rouge, en gros, pointant sur ce fichier : elle restera invisible tout le
culte et apparaitra seule au moment ou l'orateur depasse. Aucun script,
aucune condition a ecrire.

Meme principe pour avant_debut.txt, qui se vide des que le culte demarre.

7. SI QUELQUE CHOSE NE VA PAS
===============================================================================

L'application ne demarre pas sous Linux, message
"Could not find the Qt platform plugin xcb"
    Le greffon d'affichage de Qt manque. Il est declare par le paquet .deb,
    donc cela n'arrive que si vous avez installe avec "dpkg -i" au lieu de
    "apt install ./". Reprenez avec apt, ou installez le greffon :
        sudo apt install qt6-qpa-plugins

L'application ne demarre pas sous Windows, message sur une DLL manquante
    L'archive n'a pas ete extraite : vous lancez l'exe depuis l'apercu du
    ZIP. Extrayez le dossier puis relancez.

OBS n'affiche rien
    Verifiez que la source Texte pointe bien sur le fichier et que
    "Lire depuis un fichier" est coche. Ouvrez ensuite le dossier de sortie
    (menu Affichage > Ouvrir le dossier de sortie) et regardez si les
    fichiers changent quand un minuteur tourne.

OBS affiche des valeurs qui sautent d'une seconde a l'autre
    Deux copies de TimeOverlay tournent en meme temps. Fermez-en une.

Les dates s'affichent en anglais
    L'application suit la langue du systeme. Reglez la langue de votre session
    en francais, ou changez le format dans Outils > Parametres.

Le mode d'emploi complet est dans l'application : menu Aide > Mode d'emploi,
ou la touche F1. Ses liens ouvrent directement l'ecran concerne.
